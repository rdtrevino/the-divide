# Two Rounds per Day: Same Order vs Snake Order

Date: 2026-11-15. V35 Open Game. 3,000 games per line on the same seeds, plus 3,000 games each of one smart bot against random players and one random player against smart bots.

- **V35:** one turn each per Day.
- **Two rounds, same order:** 1, 2, 3 then 1, 2, 3 (the Long Game, variant `two-rounds`).
- **Snake:** 1, 2, 3 then 3, 2, 1 (variant `snake-rounds`).

## Results

3 players, 4 players in brackets.

| Measure | V35 | Two rounds, same order | Snake |
|---|---|---|---|
| Real decisions per player | 33.2 (33.4) | 54.8 (54.9) | 54.8 (54.9) |
| Skill edge (smart vs random; 1.00 is chance) | 2.46 (2.95) | 2.67 (3.35) | 2.69 (3.31) |
| Random player vs smart bots | 0.14 (0.12) | 0.10 (0.09) | 0.09 (0.10) |
| Day 3 leader goes on to win | 62% (55%) | 65% (56%) | 63% (55%) |
| Final-Day comebacks | 19% (23%) | 17% (24%) | 18% (25%) |
| Winning Glory | 12.4 (12.4) | 14.0 (13.7) | 13.8 (13.7) |
| Winning margin | 3.0 (2.4) | 2.9 (2.5) | 2.9 (2.4) |
| Celestial spread (lower is fairer) | 0.12 (0.16) | 0.21 (0.23) | 0.21 (0.24) |

## Turn position

Average Glory gained per Day by position in that Day's order (first player first).

| Order | 3 players | 4 players |
|---|---|---|
| V35 | 1.52, 1.57, 1.61 | 1.37, 1.47, 1.55, 1.52 |
| Two rounds, same order | 1.83, 1.84, 1.84 | 1.66, 1.70, 1.73, 1.71 |
| Snake | 1.85, 1.84, 1.72 | 1.73, 1.71, 1.69, 1.62 |

In V35, acting late is an advantage: at 4 players the first seat earns about 0.18 less per Day than the third. Two rounds in the same order nearly erase that gap. Snake order flips it: the first player also takes the Day's last turn, so the player in the last seat falls behind by about 0.13 per Day at 3 players and 0.11 at 4.

Both two-round orders unbalance the same two Celestials. The Dominion's fourth card is worth much more when a hand has to last two turns, and the Patron's once-per-Day power is spread over twice as many turns.

## Takeaway

Snake order and same order are nearly identical on decisions, skill and comebacks. The real difference is turn position: same order is the fairer of the two, and snake order hands the first player an edge. Either way, two rounds per Day would need a Dominion and Patron adjustment before it becomes the standard game.
