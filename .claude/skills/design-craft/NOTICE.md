# design-craft: sources and credits

Written for Last Set Studio and its projects, 2026-11-23. The text is original; the ideas are synthesised from:

- **pbakaus/impeccable** (Apache License 2.0, https://github.com/pbakaus/impeccable): the design loop (ground →
  direction → build under a craft floor → separate finish review → document), visitor modes, the direction contract,
  the craft floor and refuse list, the critique rubric (specificity verdict, Nielsen scoring, personas, P0–P3), the
  catalogue of machine-made tells, and the refine verbs (bolder, quieter, distill, delight, overdrive and the rest).
- **meta/astryx** (MIT, Copyright 2026 Meta Platforms, Inc., https://github.com/meta/astryx): token layers and
  theming as custom-property overrides, parametric scales, frame-first layout, proximity before containment, one
  content line per region, the review protocol ("never turn missing evidence into a pass"), accessibility rules.
- **VoltAgent/awesome-design-md** (MIT, Copyright 2026 VoltAgent, https://github.com/VoltAgent/awesome-design-md):
  the DESIGN.md format, and what separates distinctive design systems from generic ones (the swap test, named rules,
  tie-breakers).
- Ourly (`rdtrevino/tandem`) and Last Set Studio's own design lessons: one idea that carries meaning, budgets as
  ratchets, brand rules tested in CI, owner decisions as questionnaires.

No code from these projects is included. `scripts/shoot.mjs` is original.
